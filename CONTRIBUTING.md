# Contributing

Thank you for your interest in Torn Bargain Finder.

## Rules

- Keep the code clean and documented.
- Test changes before submitting.
- Follow the existing coding style.
- Do not add features that violate Torn's rules.

## Reporting bugs

Open a GitHub Issue with:
- Description
- Steps to reproduce
- Screenshots (if available)

## Feature requests

Feature requests are welcome through GitHub Issues.

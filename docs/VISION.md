# Torn Toolkit Vision

Torn Toolkit is an open-source toolkit for Torn PDA and Tampermonkey.

## Goals

- Fast
- Lightweight
- Modular
- Open Source
- Easy to extend

## Modules

- Bargain Finder
- Bazaar
- Travel
- War
- Crimes
- Casino
- Racing
- Inventory
- Faction
- Statistics
